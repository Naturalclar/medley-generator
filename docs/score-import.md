# 歌詞・コードのURL取り込みと演奏ビュー（#357）

確認日: 2026-11-11。

当初のIssueは調査のみを対象としていたが、その後「357を実装完了するまで続けて」と指示されたため、調査結果と実装をこの変更にまとめる。利用者から、UtaTen・ChordWikiの取得・保存に関する許諾は未取得との回答があった。サイト別の取得は既定で無効であり、許諾を取得したことを実装・テストで代替したとは扱わない。

## 決定した範囲

- 配信はAvvy、演奏時の表示はiPad。Macでも編集できる。OBS連携と端末間の自動同期は作らない。
- 曲ID、習熟度、作品コード、作者、YouTube、既存の選曲・申請準備機能は維持する。
- 私用の譜面は公開曲JSONから分離し、localStorageの `medley-generator:scores:v1` に保存する。
- 本文はプレーンテキストまたはChordPro。コード位置を保って上段に表示し、半音移調・♯/♭切り替え・文字サイズ・自動スクロール・ページ送り・曲送りを提供する。
- 譜面記載キーとカポは原譜の情報として表示する。移調は表示コードと記載キーに適用し、カポは自動変更しない。推奨カポや実音キーの推定はしない。
- 既存の生成セトリを端末に保存し、再起動後に復元する。複数セトリの管理・フル曲CRUD・歌唱履歴は#357の取り込み機能とは別の拡張で、この変更には含めない。既存の申請進捗を歌唱履歴として使わない。
- JSONには譜面と現在のセトリの曲ID・生成日時を含める。表示サイズ・移調・スクロール速度・申請進捗は含めない。未知の曲IDの譜面も保持・編集できるが、公開曲プールにない曲はセトリに復元できない。
- 初回オンライン表示で公開アプリ一式をService Workerへ保存し、準備完了後はオフラインで再起動・譜面編集／閲覧できる。取得APIと個人の譜面はService Workerのキャッシュ対象外。

UtaTen・ChordWikiの公開資料と検索で、今回の用途に利用可能と確認できる一般公開の本文取得APIは見つからなかった。APIが存在しないと断定はしない。規約にあるYouTube APIの説明は、歌詞・ChordProを配布するAPIの説明ではない。

問い合わせは実施していない。問い合わせ時には、URL指定による単曲取得、配信者本人の端末内表示、ローカル保存、オフライン利用、移調表示、Mac/iPad間のJSON移行、譜面を公開しない構成について確認する。返答によって必要な制約・クレジット・削除や保存期限の仕様を更新する。

## 構成

既存のReact・TypeScript・Viteは維持する。ブラウザから別サイトを読むにはCORS等の制約があるため、同一オリジンの `GET /medley-generator/api/score-import?url=...` を用意した。

- `server/score-import.mjs`: 対象サイトとパスを固定した取得処理。許諾設定の検査、10秒タイムアウト、2MB上限、リダイレクト拒否。外部サイトのCookie・認証情報は送らない。
- `server/start.mjs`: ビルド済みアプリと取得APIを同じオリジンで配信するNodeサーバー。既定は127.0.0.1。APIの同時取得は最大2件、別オリジンからのブラウザリクエストを拒否する。
- `src/lib/scoreImport.ts`: URL検査、取得レスポンスの検証、HTMLからのテキスト抽出。取得HTMLをDOMへ挿入しない。スクリプト・スタイル等は利用しない。
- `src/lib/scores.ts`: 保存・バックアップの型検証、ChordProの解析・メタデータ抽出・移調。
- `src/ScoreLibrary.tsx`: 譜面編集、取り込み確認、移行確認、演奏ビュー。
- `offline-plugin.ts`: ビルドごとの公開アプリ一式のキャッシュ。旧バージョンと新バージョンのファイルが混ざらないようにする。

GitHub PagesだけではAPIを実行できない。既存Pages配信では本文の編集・保存・移行・演奏は利用できるが、URL取り込みには別の配信構成が必要。今回は既存の公開デプロイを変更していない。

### 起動

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

`http://127.0.0.1:4174/medley-generator/` を開く。取得機能は許諾設定なしでは403を返し、外部サイトへアクセスしない。

許諾を確認した運用者が、必要な範囲の設定をサーバー環境変数に設定する。

- `UTATEN_IMPORT_PERMISSION`: UtaTenの取得・保存に関する利用条件・許諾の記録
- `CHORDWIKI_IMPORT_PERMISSION`: ChordWikiの取得・保存に関する利用条件・許諾の記録

値は譜面の出典・利用条件として端末に保存・書き出されるため、秘密情報や契約書本文を入れない。変数名の設定自体は利用許諾を与えるものではない。許諾範囲が一部の楽曲・用途に限られる場合は、公開運用に先立ち、その範囲をサーバー側で限定する追加対応が必要。

iPadでオフライン起動するには、iPadから接続可能なHTTPS配信が必要。Nodeサーバーを利用する場合はTLS終端とアクセス制限を用意する。単に `HOST=0.0.0.0` に変えるだけでは、HTTPS・認証・外部公開時の濫用防止は提供されない。公開インターネット向けの匿名プロキシとしては配信しない。環境変数設定・外部公開・契約や問い合わせは今回実施していない。

## 操作・保存・エラー

1. 曲を検索して譜面編集を開く。
2. 対応するUtaTen／ChordWiki URLを入力して取得する。既存の未保存編集を置き換える際は確認する。
3. 曲名・アーティスト・本文・取得元・利用条件を確認し、必要なら編集する。取得のみでは永続化しない。
4. 保存後、演奏ビューを開く。セトリに含まれる曲はセトリの順で、含まれない曲はその曲単独で開く。
5. 元の本文を保持したまま表示を移調する。別ページの歌詞とコードを自動的には結合しない。構成の差による位置ずれを避けるため、ChordWikiのChordProを使う場合は、その歌詞とコードを一体として扱う。

未対応URL・許諾未設定・通信失敗・ページ形式変更時はエラーと元ページへのリンクを表示し、保存済み譜面を変更しない。取得は中止でき、曲を切り替えた後の遅延レスポンスは編集先へ反映しない。保存失敗は成功扱いにしない。

JSON取り込みは形式を検証してから追加／同じIDの件数を表示する。同じIDは利用者が選択したものだけ置き換える。更新日時の新しさで自動上書きしない。直前の取り込みを画面内で取り消せる。取り消し情報はメモリ内のみで、再読み込み後には残らない。JSONは個人の譜面を含むので公開リポジトリへ置かない。

既存の保存データが壊れている場合は、空の状態で自動上書きせず保存を停止して知らせる。ブラウザデータ削除に備え、JSONを別の場所へ保管する。

## 検証と未完了条件

自作の短いテスト用本文を使用し、第三者の歌詞本文をテストfixtureとしてコミットしない。

- `pnpm test`: 移調の主要修飾・分数コード・正負の半音・循環・表記、保存形式検査、JSON往復、メタデータ等。
- `pnpm run test:server`: URL制限、許諾未設定時の取得拒否、レスポンス・サイズ制限・取得失敗。
- `pnpm run test:ipad`: WebKitでiPad相当の編集・演奏・移行を検証。オフライン再起動は専用の配信元を停止して検証する（[Playwrightの既知の模擬不具合](https://github.com/microsoft/playwright/issues/42775)）。実機iPadの検証を代替したとは扱わない。
- `pnpm run test:e2e`: 取得→確認→保存、取得HTMLの非実行、移調、再読み込み、JSON競合・取り消し、タブレット幅、オフライン再起動、既存の選曲・申請操作。

テストはサイトの許諾を代替しない。実サイトから両方の取り込みが利用可能になったという受け入れ条件は、許諾未取得・ChordWiki実データ検証未完了のため未達。#357を閉じる根拠にしない。
