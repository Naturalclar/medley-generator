このアプリについて

「メドレーセトリ生成」(以下、本アプリ)は、配信で演奏するメドレーの曲目を 自動で組み、歌詞・コードを端末内で編集・表示する Web アプリです。 選曲・編集・保存はブラウザ内で行います。URL取り込みを有効にした環境では、取得用サーバーを利用します。

収集する情報

本アプリは氏名・メールアドレスの登録を求めません。アクセス解析ツールや広告は導入していません。 譜面本文・セトリ・申請進捗はブラウザ内に保存します。ブラウザデータを削除すると失われます。 URL取り込みでは指定URLを取得用サーバーへ送信し、サーバーが取り込み元へアクセスします。 取得処理は本文やURLをデータベース・ファイルへ保存せず、アクセスログも出力しません。 ホスティングやプロキシの通信ログは各配信環境の設定に依存します。

YouTube アカウントへのアクセス

本アプリには、生成したセトリを閲覧者自身の YouTube アカウントに プレイリストとして保存する任意の機能があります。この機能を使う場合に限り、 Google のログイン画面で以下の権限を要求します。

  • https://www.googleapis.com/auth/youtube

権限の用途

この権限は、次の目的にのみ使用します。

  • 閲覧者自身のアカウントに、限定公開のプレイリストを新規作成すること
  • 作成したそのプレイリストに、セトリの曲を追加すること

既存のプレイリスト・動画・チャンネル情報の読み取り、変更、削除は一切行いません。 視聴履歴や登録チャンネルにもアクセスしません。

アクセストークンの取り扱い

Google から受け取ったアクセストークンは、ブラウザのメモリ上にのみ保持 します。localStorage・sessionStorage・Cookie などへの保存や、 外部サーバーへの送信は行いません。ページを再読み込みまたは離脱した時点でトークンは失われます。

第三者への提供

YouTube連携では、プレイリストを作成するために YouTube Data API (Google)へ送信します。 URL取り込みの送信先は、下記の「譜面の取り込みとバックアップ」を参照してください。

Google API Services User Data Policy

本アプリによる Google API から取得した情報の利用および他社への移転は、 Google API Services User Data Policy(Limited Use requirements を含む)に準拠します。

権限の取り消し

付与した権限は Google アカウントの「サードパーティ製アプリとサービス」からいつでも取り消せます。

譜面の取り込みとバックアップ

URL取り込みは、対象サイトの利用条件・許諾を確認して有効にした環境で利用できます。 取得元にはサーバーのIPアドレスと指定ページへのリクエストが伝わります。 閲覧者のCookie・YouTubeのアクセストークン・編集中の本文は取り込み元へ送信しません。 UtaTen・ChordWikiの取得は既定で無効です。

譜面JSONは利用者の操作で端末へ書き出し、ファイルを選択して読み込みます。 ファイルは自動送信されません。譜面本文や利用条件を含むため、保管・共有先は利用者が管理してください。 オフライン用のキャッシュには公開アプリと曲一覧のみを保存し、取得APIの応答は保存しません。

曲データの公開について

公開曲一覧は、リポジトリ内の songs.json に含まれる 曲名・アーティスト名・習熟度などの情報のみで、 公開エンドポイントとしても配信されています。 個人を特定できる情報は含めていません。端末内に保存した譜面本文・セトリ・申請進捗は、この公開データには追加しません。
