このアプリについて

「メドレーセトリ生成」(以下、本アプリ)は、配信で演奏するメドレーの曲目を 自動で組むための Web アプリです。サーバーやデータベースを持たない静的サイトで、 すべての処理は閲覧者のブラウザ内で完結します。

収集する情報

本アプリは個人情報を一切収集しません。 送信先となるサーバーを持たないため、氏名・メールアドレス・IPアドレス等を 取得・保存することはありません。アクセス解析ツールや広告も導入していません。

YouTube アカウントへのアクセス

本アプリには、生成したセトリを閲覧者自身の YouTube アカウントに プレイリストとして保存する任意の機能があります。この機能を使う場合に限り、 Google のログイン画面で以下の権限を要求します。

  • https://www.googleapis.com/auth/youtube

権限の用途

この権限は、次の目的にのみ使用します。

  • 閲覧者自身のアカウントに、限定公開のプレイリストを新規作成すること
  • 作成したそのプレイリストに、セトリの曲を追加すること

既存のプレイリスト・動画・チャンネル情報の読み取り、変更、削除は一切行いません。 視聴履歴や登録チャンネルにもアクセスしません。

アクセストークンの取り扱い

Google から受け取ったアクセストークンは、ブラウザのメモリ上にのみ保持 します。localStorage・sessionStorage・Cookie などへの保存や、 外部サーバーへの送信は行いません。ページを再読み込みまたは離脱した時点でトークンは失われます。

第三者への提供

本アプリが情報を送信する先は、プレイリストを作成するための YouTube Data API (Google)のみです。それ以外の第三者へのデータ提供・販売は行いません。

Google API Services User Data Policy

本アプリによる Google API から取得した情報の利用および他社への移転は、 Google API Services User Data Policy(Limited Use requirements を含む)に準拠します。

権限の取り消し

付与した権限は Google アカウントの「サードパーティ製アプリとサービス」からいつでも取り消せます。

曲データの公開について

本アプリが扱う曲データは、リポジトリ内の songs.json に含まれる 曲名・アーティスト名・習熟度などの情報のみで、 公開エンドポイントとしても配信されています。 個人を特定できる情報は含めていません。

本ポリシーの変更

内容を変更した場合は、このページを更新し、最終更新日を改めます。
